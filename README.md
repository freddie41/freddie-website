# 🚀 Federico Cuelho — Personal Portfolio

A sleek, high-performance personal portfolio built with **Next.js**, **TypeScript**, and modern web practices.

---

### ✨ Features

- **⚡ Lightning Fast:** Built on the Next.js App Router for optimal SSR and static generation.
- **🎨 Modern UI:** Clean, responsive design crafted with reusable components.
- **📱 Fully Responsive:** Seamless layout experience across desktop, tablet, and mobile.
- **🛠️ Agent-Ready:** Configured with custom agent and AI guidelines (`AGENTS.md`, `CLAUDE.md`).

---

### 🛠️ Tech Stack

| Category      | Technology           |
| :------------ | :------------------- |
| **Framework** | Next.js (App Router) |
| **Language**  | TypeScript           |
| **Styling**   | CSS / Tailwind CSS   |
| **Linting**   | ESLint               |

### 🚀 Getting Started

First, clone the repository and install dependencies:

```bash
git clone [https://github.com/freddie41/freddie-website.git](https://github.com/freddie41/freddie-website.git)
cd freddie-website
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
